Расширенный поиск ВКонтакте

Разбивает большой поисковой запрос на маленькие и сохраняет уже просмотренные. Это поможет обойти ограничение в 1000 пользователей и просто удобно! (Подробная инструкция в README.md)

ВНИМАНИЕ ПРОЕКТ СКОРО БУДЕТ УДАЛЕН.
Если вы хотите продолжить использовать его, то:
1. СКАЧАЙТЕ → архив с сайтом и распакуйте его.
2. Установите простой локальный сервер, например ok200 и установите.
3. Добавить в локальный сервер папку с проектом и добиться, чтобы он открывался локально в браузере по адресу Http://localhost:8080 или похожем если порт 8080 занят.
4. Экспортировать уже просмотренные ссылки с этого сайта.
5. Импортировать их в свой локальный сайт.

Проект нужно запускать обязательно через локальный сервер, просто открыть index.html в браузере как файл будет не достаточно - не будет работать правильно.
